# 🎓 Student Academic Performance Prediction System

A modern, full-stack web application that uses **Machine Learning (Linear Regression)**
to predict a student's **final academic marks** based on four academic input features.

Built as a **BCA Minor Project** combining ML + Web Development + Database + Data Visualization.

---

## 📌 Project Objective

To provide students with an early, data-driven prediction of their likely final marks so they
can take corrective action *before* exams. The system combines a trained ML model with a
clean, modern dashboard, prediction history, analytics and model transparency.

---

## ✨ Features

- 🔐 **Secure Login** — Student ID + hashed password (Werkzeug), session-based auth
- 🏠 **Dashboard** — Latest prediction, grade, category, trend chart
- 🎯 **Prediction Page** — Input form with validation and instant prediction
- 📈 **Analytics** — Dataset scatter plots + personal prediction trend
- 📜 **Prediction History** — Per-student, stored in SQLite
- 👤 **Profile Page** — Student identity and activity summary
- 🧠 **Model Info Page** — Live metrics loaded from `model_accuracy.json`
- ℹ️ **About Page** — Project details and technology stack

---

## 🧠 Machine Learning Methodology

The ML pipeline is intentionally fixed and reproducible.

| Component        | Value                                          |
|------------------|------------------------------------------------|
| Algorithm        | **Linear Regression**                          |
| Target Variable  | `Final_Marks`                                  |
| Input Features   | `Study_Hours`, `Attendance`, `Previous_Marks`, `Assignments_Completed` |
| Train/Test Split | 80% / 20%                                      |
| Random State     | 42                                             |
| Dataset          | `dataset/students.csv` (~100 records)          |

### Pipeline

```
Dataset → Feature Selection → 80/20 Split (random_state=42)
        → LinearRegression → Evaluation (R², MAE, RMSE)
        → pickle → models/student_model.pkl
        → Flask loads model → Prediction
```

### Model Performance

Actual metrics are calculated from the dataset at training time and saved to
`models/model_accuracy.json`. **Nothing is hard-coded.**

## 🚀 Installation & Setup

### 1. Clone / extract the project

```bash
cd BCA_MINOR_PROJECT
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Train the model (required first time)

```bash
python train_model.py
```

This generates:
- `models/student_model.pkl`
- `models/model_accuracy.json`

### 5. Run the web application

```bash
python main.py
```

Open **http://127.0.0.1:5000** in your browser.

The SQLite database is created automatically on first run.

## 📊 Grading Rule

The grade and performance category are derived **separately** from the ML prediction:

| Marks Range | Grade | Category            |
|-------------|-------|---------------------|
| ≥ 90        | A+    | Excellent           |
| 80 – 89     | A     | Very Good           |
| 70 – 79     | B+    | Good                |
| 60 – 69     | B     | Above Average       |
| 50 – 59     | C     | Average             |
| 40 – 49     | D     | Pass                |
| < 40        | F     | Needs Improvement   |
